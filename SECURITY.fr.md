# Politique de sécurité

## Signaler une vulnérabilité

Merci d'envoyer les signalements de sécurité en privé à
[mybudget.affidavit980@passmail.net](mailto:mybudget.affidavit980@passmail.net).
Ne publiez pas les détails d'une vulnérabilité dans une issue ou une pull request
avant de vous coordonner avec le mainteneur.

Indiquez, si possible :

- La version de l'application, la version d'Android et le composant concerné.
- Les étapes de reproduction avec des données fictives, le comportement attendu
  et celui observé.
- L'impact potentiel et les journaux ou captures utiles, après masquage des
  informations sensibles.

N'envoyez jamais de données financières réelles, de base personnelle, de mots de
passe, de jetons ou de clés de signature. Utilisez une installation de test et
partagez uniquement les informations nécessaires à la reproduction du problème.

## Versions et suivi

Les correctifs de sécurité ciblent la dernière release. Les anciennes versions
ne bénéficient d'aucune garantie de rétroportage ; signalez un problème même si
vous ne pouvez pas le reproduire sur la dernière version.

Le mainteneur évaluera les signalements et coordonnera les éventuels correctifs
et leur divulgation publique avec la personne ayant signalé le problème. Aucun
délai de réponse ou de résolution n'est garanti.

Pour les bugs ordinaires ou les demandes de fonctionnalités, utilisez les
[issues du dépôt](https://github.com/Azouriss/MyBudget/issues), sans données
personnelles.
