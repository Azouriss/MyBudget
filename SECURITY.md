# Security policy

## Report a vulnerability

Please send security reports privately to
[mybudget.affidavit980@passmail.net](mailto:mybudget.affidavit980@passmail.net).
Do not disclose vulnerability details in a public issue or pull request before
coordinating with the maintainer.

Include, when available:

- The app version, Android version and affected component.
- Steps to reproduce using fictional data, and the expected and observed behavior.
- The potential impact and any relevant redacted logs or screenshots.

Never send real financial records, a personal database, passwords, tokens or
signing keys. Use a test installation and share only the information needed to
reproduce the issue.

## Versions and follow-up

Security fixes target the latest release. Older versions have no guaranteed
backports; please report an issue even if you cannot reproduce it on the latest
version.

The maintainer will assess reports and coordinate any fix and public disclosure
with the reporter. No response or resolution deadline is guaranteed.

For ordinary bugs or feature requests, use the repository's
[issues](https://github.com/Azouriss/MyBudget/issues), without personal data.
