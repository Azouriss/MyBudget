# Inter

Inter Regular, Medium, SemiBold et Bold, sous licence SIL Open Font License 1.1.
La licence et les mentions des auteurs sont conservées dans `LICENSE.txt`.

Source : archive npm `@fontsource/inter` 5.2.8, retrouvée dans un cache local.
Les fichiers Latin WOFF ont été décompressés en TTF par
`scripts/prepare-fonts.py`, sans modifier les glyphes ni les noms.
L'intégrité SHA-512 de l'archive et les sommes de contrôle SFNT des TTF sont
vérifiées par le script. Aucun téléchargement de police n'a lieu à l'exécution.

Pour reproduire depuis une copie locale de la même archive :

```sh
python3 scripts/prepare-fonts.py /chemin/vers/inter-5.2.8.tgz
```

Source : archive npm `@expo-google-fonts/playfair-display` 0.4.2, fichiers TTF
originaux, sans modification. Licence SIL OFL : `PlayfairDisplay-LICENSE.txt`.
Les deux licences sont consultables dans Plus. Aucun chargement distant à
l’exécution.
